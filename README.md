# PAP2027-RosattaAutomotive
A minha PAP consiste no desenvolvimento da Rosatta Automotive, uma marca fictícia de automóveis de luxo. Pretendo criar uma plataforma web bilingue para explorar e personalizar veículos, guardar configurações e marcar Test Drives. O sistema terá uma área de cliente e um painel de administração, desenvolvido com HTML, CSS, JavaScript, PHP e MySQL.
