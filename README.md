## Descrição

A minha PAP consiste no desenvolvimento da Rosatta Automotive, uma marca fictícia de automóveis de luxo criada por mim. Pretendo desenvolver uma plataforma web bilingue (português, e inglês) que permita aos utilizadores explorar diferentes modelos de veículos, personalizá-los através de um configurador interativo e guardar as suas configurações. A plataforma permitirá também solicitar Test Drives e terá um painel de administração para gerir os conteúdos e as operações do website.

## Objetivos

- Desenvolver uma plataforma web moderna, responsiva e bilingue.
- Implementar um configurador interativo de veículos com atualização de preços.
- Criar um sistema de gestão de clientes, veículos e reservas.
- Aplicar conhecimentos de programação, bases de dados e segurança informática.

## Funcionalidades

### Núcleo mínimo (obrigatório)
- [ ] Página inicial e apresentação da marca.
- [ ] Catálogo de veículos com pesquisa e filtros.
- [ ] Páginas individuais com informações dos veículos.
- [ ] Sistema de registo, login e logout.
- [ ] Configurador de veículos com cálculo automático do preço.
- [ ] Base de dados MySQL integrada com PHP.
- [ ] Painel de administração com operações CRUD.
- [ ] Sistema de pedidos de Test Drive.

### Extras (se houver tempo)
- [ ] Garagem virtual para guardar configurações.
- [ ] Painel de estatísticas administrativas.
- [ ] Comparação entre diferentes modelos.
- [ ] Integração de modelos 3D no configurador.
